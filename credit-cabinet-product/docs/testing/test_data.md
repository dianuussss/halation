# Синтетические данные и тестовые учётки (D9)
Статус: готов · Версия: 1.0 · Обновлено: 2026-10-24
Связано с: R-13, R-20 · огр. 03 · [scoring_and_decision §7](../process/scoring_and_decision.md) · seed: [`seed/`](../../seed) · генератор [`tools/reference/gen_seed.py`](../../tools/reference/gen_seed.py)

## Решение в одном абзаце
Семь вымышленных компаний — у каждой один «характер» и один заранее известный путь по state machine, вместе они покрывают все ветки: авто-одобрение с изменениями, другой продукт, авто-отказ, ручное рассмотрение, запрос эксперта с повторным скорингом, стоп-фактор реестра и сбой источника. Ожидаемые баллы посчитаны эталонным кодом, а не вручную, и проверяются автотестом. ИНН и ОГРН имеют валидную контрольную сумму, но код региона «00» не существует — пересечение с реальными компаниями исключено. Seed поднимается одной командой.

## 1. Требования к данным
- ИНН/ОГРН/ОГРНИП — валидная контрольная сумма, регион «00» (не существует); ФИО, адреса, названия — условные («г. Условный»).
- Моки ЕГРЮЛ/ЕГРИП, «Прозрачный бизнес», БКИ, внутренние данные отвечают по ИНН из seed; неизвестный ИНН → `404`.
- Пересоздание: `make seed` или при старте контейнера `SEED_ON_START=true`; кнопка «Сбросить демо» в B-05 (`POST /admin/demo/reset`).
- Пароли в `seed/users.json` — только bcrypt-хэш; открытый пароль демо-учёток указан в README как демонстрационный.
- Пересчёт ожиданий: `python3 tools/reference/expected_outcomes.py` (as-of по умолчанию 2026-10-24; срок деятельности считается от даты подачи).
