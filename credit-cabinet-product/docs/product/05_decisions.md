## Отклонения от формулировок ТЗ

| ID | Было в ТЗ | Стало | Причина |
| --- | --- | --- | --- |
| D-07 | Демо-документ для NEEDS_INFO — «выписка по счёту» | «Налоговая декларация за последний год» | Анна — клиент банка с р/с 20 мес.: требовать у неё выписку из собственного банка нелогично; декларация обязательна для «Экспресса» |
| D-08 | T14: «сумма > лимита авто-решения → MANUAL_REVIEW» | Превышение cap класса → автоматический контроффер (T13); в MANUAL — класс C, залог, неполные данные | Матрица ТЗ для класса B прямо требует «больше → APPROVED_WITH_CHANGES»; так меньше ручной работы (P-B2) |
| D-09 | Порядок контроффера не задан («снижение суммы / увеличение срока / другой продукт») | Детерминированный порядок: cap → как есть → срок → другой продукт → сумма → отказ | Детерминизм демо (правило ТЗ №7) и сохранение нужной клиенту суммы в первую очередь |
| D-10 | C1: «3 млн ₽ или 4 млн ₽ на 24 мес.» | 3 млн ₽ / 12 мес. | Cap класса B — ограничение суммы, срок его не снимает; один ожидаемый исход на компанию |
| D-11 | Нет выхода из SIGNING, кроме подписи | Добавлены T23 (истёк оффер) и T24 (отказ на подписании) | Без них SIGNING — тупиковый нетерминальный статус |
| D-12 | T22: отзыв из DRAFT / SUBMITTED / VALIDATING / NEEDS_INFO / MANUAL_REVIEW | Только DRAFT, NEEDS_INFO, MANUAL_REVIEW | В автоматических статусах заявка находится секунды, отзыв там порождает гонки |
| D-13 | T10 — только недоступность источника | + ИНН не найден в реестре | Иначе заявка с ручными реквизитами не имеет пути после ENRICHING |
| D-14 | Долговая нагрузка: формула без уточнения ставки | На скоринге — базовая ставка продукта, в оффере — ставка класса; для линии — проценты на лимит | Класс ещё не известен на этапе скоринга; модель линии объясняет, почему она подходит сезонному бизнесу |
| D-15 | Принятие оффера можно было трактовать как ACTION («требуется действие») | Оффер — STATUS с кнопкой; ACTION только для блокирующих запросов банка | Иначе закреплённая карточка вытесняет полезные подсказки; соответствует таблице демо ТЗ (шаг 4) |
| D-16 | E2E — 8 сценариев | 9 (добавлен E2E-09: авто-одобрение «как есть» + отказ от оффера) | Без него T12 и T19 не покрыты ни одним сценарием |
